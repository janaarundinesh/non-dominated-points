# Repository notes for coding agents

## Commits

**No AI attribution.** Do not add a "Generated with" line, a `Co-Authored-By`
trailer, or any other attribution footer to commit messages. End the message at
its own last line.

Match the existing history instead: short, plain, lowercase descriptions of what
changed.

```
implemented Round Robin RING method
moved sorting outside the maxima loop
```

## Scope

Generated benchmarks, CSVs and figures are meant to be reproducible from the
committed drivers and scripts, not hand-edited.
